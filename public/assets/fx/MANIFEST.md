# FX Assets Manifest

Sprite assets for canvas particle effects and a possible tavern backdrop.
All files are unmodified, byte-identical copies of CC0 originals from Kenney
asset packs, renamed to lowercase snake_case. Downloaded 2026-11-24 from
kenney.nl. No attribution is required for any of these files.

## Notes

- The 512x512 particle sprites are the pack's native resolution and are
  soft, mostly semi-transparent shapes. Downscale at build time if payload
  size matters; CC0 permits any modification.
- More sprites from the same packs (magic swirls, twirls, flares, dirt,
  scorch marks, dungeon doors, chests, campfires, a two-tile fireplace) were
  available and can be added the same way if needed.
